# primo.global-menu

macOS-style app menu bar for the focused window, driven by the omarchy-global-menu-bridge daemon.

https://github.com/PrimoGameStudio/omarchy-global-menu-bridge

To install:
omarchy plugin add https://github.com/PrimoGameStudio/primo.global-menu.git --enable

To Uninstall:
omarchy plugin remove primo.global-menu --yes
